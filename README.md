# Oleg Bot — проводник по этапам внутреннего развития

Телеграм-бот, который помогает определить, на каком этапе взаимодействия с сознанием находится человек, и подбирает практики для его этапа.

## Возможности

- 📝 Тест из 12 вопросов с определением одного из четырёх типов
- 📖 Описания четырёх типов людей
- 🧘 Практики, подходящие каждому типу
- 📅 30-дневная программа ежедневных заданий по типу пользователя (новое задание открывается каждый календарный день)
- Команды: `/start`, `/test`, `/types`, `/practices`, `/day`

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен:

```bash
cp .env.example .env
```

3. Установите зависимости и запустите:

```bash
pip install -r requirements.txt
python bot.py
```

## Запуск в Docker

```bash
docker build -t oleg-bot .
docker run -d --env-file .env --name oleg-bot oleg-bot
```

## Структура

- `bot.py` — логика бота (aiogram 3, long polling)
- `content.py` — тексты: типы, практики, вопросы теста
- `tasks.py` — 30-дневные программы заданий по типам
- `db.py` — SQLite-хранилище (тип пользователя, прогресс программы); файл `bot.db` создаётся автоматически

## Как считается результат

Каждый вариант ответа (А/Б/В/Г) соответствует типу 1–4. Побеждает тип с наибольшим числом ответов; при равенстве берётся более ранний тип.

## 30-дневная программа

После теста тип пользователя сохраняется, и ему становится доступна программа ежедневных заданий (кнопка «Задание дня» или команда `/day`). День продвигается автоматически по календарю от даты старта. При смене типа (повторный тест с другим результатом) программа сбрасывается.

Сейчас заполнена программа для типа 1 (файл `tasks.py`). Программы для типов 2–4 добавляются в словарь `TASKS` по тому же формату — список из 30 строк.
